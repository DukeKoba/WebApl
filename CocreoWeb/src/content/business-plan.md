# AI事業 段階的成長ビジネスプラン

## エグゼクティブサマリー

本ビジネスプランは、AIを軸とした4段階の事業展開戦略を提示する。
個人の副業（AIアプリ開発）から出発し、AI保険代理店→地方創生AIコンサルティング→M&Aによる事業拡大へと段階的にスケールアップする。

```
Phase 1: AIアプリ副業（0〜12ヶ月）→ 年商100万円
Phase 2: AI保険代理店（12〜24ヶ月）→ 年商500〜1,000万円
Phase 3: 地方創生AIコンサル（24〜36ヶ月）→ 年商2,000〜5,000万円
Phase 4: M&A事業拡大（36ヶ月〜）→ 年商1億円〜
```

## Phase 1: AIアプリ開発副業（年間売上100万円目標）

> **市場トレンド**: GenAIアプリは2025年上半期にDL数17億回・収益$18.7億と前期比2倍に急成長中。日本はリワード動画eCPMが$17.35（Android）で世界トップクラス。

> **注意**: 2025年4月からJCT（消費税10%）がアプリストア側で自動徴収され、実質手取りが約10%減少。収益計算時に考慮が必要。

#### モデルA: 広告収益型（AdMob等）

### 1.5 成功のポイント
- **無料トライアル付きサブスク**を必ず実装（課金転換率が2%→40%超に跳ね上がる）
- **ASO（App Store Optimization）** を徹底し、検索流入を最大化
- **ニッチ市場**を狙う（例: 特定資格の学習アプリ、特定業種向けツール）
- **SNSマーケティング**（TikTok/X/YouTube）で低コスト集客
- AI APIの**キャッシュ戦略**とローカル処理併用でランニングコストを抑制
- **リワード動画広告**を積極活用（日本市場はeCPM世界最高水準）

| 項目 | 詳細 |

| 生命保険募集人資格 | 一般課程試験合格（受験料無料〜数千円） |

### 2.3 専属代理店 vs 乗合代理店（段階的戦略を推奨）

| 比較項目 | 専属代理店 | 乗合代理店 |
|---------|----------|----------------|
| 取扱保険会社 | 1社のみ | 複数社（10〜30社） |
| コミッション率 | 15〜25% | 10〜20% |
| 開業支援 | 手厚い（研修・システム提供） | 自力で構築が必要 |
| 顧客提案力 | 限定的 | 最適提案が可能（AI比較に適合） |
| 独立性 | 低い | 高い |
| 参入ハードル | **低い** | 高い（有資格者2名以上） |
| **AI活用との相性** | △ | **◎（複数社比較でAIの強みが活きる）** |

> **推奨戦略**: まず**専属代理店**で参入障壁を下げてスタートし、年商5,000万円を超えた段階で**乗合代理店**へ移行。AI複数社比較機能は乗合化後に最大の差別化要因となる。

### 4.3 バリュエーション目安

| 業種 | EBITDA倍率 | 備考 |
|------|----------|------|
| 保険代理店 | 3〜5倍 | ストック収入の評価次第で上振れ |
| IT・ソフトウェア | 5〜8倍 | SaaS型は10〜20倍超も |
| コンサルティング | 4〜6倍 | 人材・顧客基盤が評価ポイント |
| 製造業 | 3〜5倍 | 中小企業全体平均は約5.4倍 |

**計算式**: 事業価値 = EBITDA x 倍率 + 現預金 - 有利子負債
**年買法**: 株式価値 = 時価純資産 + 営業利益 x 2〜5年分（のれん代）
