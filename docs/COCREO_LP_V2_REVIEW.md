# 実装LPレビュー第2弾 ＋「自走支援型」転換の判定

作成日: 2026-08-08
対象: localhost:3000 で実装された新LP（スクリーンショット2枚で確認）と、運営者の方向転換構想「BPRやRPAを、Claude CodeやCodexなどを活用して御社内で自走できるレベルまで支援します」
検証方法: LPコピー/CVR・買い手パネル（6名代理店経営者A / 40名代理店役員D / 保険会社の代理店支援E）・事業モデル・デザイナーの4視点×2周
関連文書: `COCREO_LP_REVISION_PLAN.md`（初版プラン）、`COCREO_BPR_PIVOT_REVIEW.md`（事業検証）

## 0. 結論（5行）

1. **「自走できるレベルまで支援」への全面転換はしない。** A=ゼロ円（学ぶ時間も意欲もない）、E=紹介不可（シャドーIT化）。ただし**3つの形に変換すれば売れる**（§2）
2. **「RPA」「BPR」は使用禁止。** Dは2019年にWinActorを初期250万+保守80万で見送った実体験があり、「Claude CodeでRPAを」は「また画面が変わったら壊れるやつか」と即連想される
3. 実装LPへの買い手判定は**Yes維持**。「訴求が沸かない」の正体は文言ではなく**「人の顔・Beforeの汚い絵・損失額・会社概要」の4欠落**＋デザイン面の「山が2つしかないリズム」
4. Eの発言から**新商材が出た**:「社内AI利用ルールと変更管理の整備」48万円。保険会社が能動的に勧められる唯一の商材＝販路ゼロの現状で最重要
5. 修正は**パッチ14件（§4）＋デザイン18項目・4.0人日（§6）**。作り直しは不要。「足りなかったのは人間の存在・汚い現実・金額の対置の3つ」

## 1. 「自走支援型」への転換は違うのか — 買い手の直接回答

### A（6名・経営者50代）: ゼロ円

> 「うちの事務2名に、新しいことを学ぶ時間はありません。研修に月4時間割いたら、その4時間分の仕事が誰かの残業になる。50代と40代の事務員に『これからはAIを使いこなしましょう』は酷な話です。**『自走できるレベルまで』は、うちには存在しない目標です**」
> 「**『自分でできるようになってください』は、私には『もう来ません』と言われているのと同じに聞こえる。** 1本目が動いたら、2本目もあなたに頼みます」

買うとしたら「納品したツールの操作説明を2時間、5万円」のみ。

### D（40名・役員）: 納品8:移行2の比率でのみ買う

- 「稟議に『社員のスキル向上』と書くと、役員会で必ず『**で、いつ何が減るのか**』と聞かれる。効果が測れない支出は通らない」
- 「担当者が辞めたら投資がゼロになる。**バス係数が外部の1人から社内の1人に移っただけ**で、むしろ悪化する——外部業者には契約で引継ぎ義務を課せるが、辞める社員には課せない」
- 買う形: **3か月60万円**（月1訪問半日×3回＋改修レクチャー＋手順書、課長1名限定）。「**名目は『保守の内製化』。『社員教育』では通らない。名目が全てです**」

### E（保険会社）: 純自走型は紹介できない

- 「社員が生成AIで作ったツールは、管理台帳への登録・変更管理・障害時対応の全部が欠けやすい。**一人が作れるようになると必ず複数人が作り始め**、営業が顧客リストを外部AIに貼る事故が起きる。保険会社が推奨した責任を負えない」
- **ただし**:「現実には代理店の若手が勝手にChatGPTを使い始めており、弊社はそれを止める手立てを持っていない。**無秩序な内製を、管理された内製に変える支援なら、弊社が代理店に勧めたい商材だ**」

### 事業モデル面の裁定

純自走型は天井を「保守キャパN=8〜12社」から「**年間新規獲得数**」に移すだけで、販路ゼロの運営者が最も弱い変数に制約が移動する。かつ自走が成立する最小条件（Excel関数を書ける担当＋週2h×12週の学習枠＋2年以内に辞めない見込み）を満たすのは**40名級のみ**で、到達可能市場が数百社→100〜200社に縮む。

## 2. 転換構想の最終形 — 3つに変換して全部残す

| 運営者の構想 | 変換後 | 対象 |
|---|---|---|
| 自走できるまで支援 | **保守の内製化パッケージ**（3か月60万・ルール表とマッピング定義の編集権を渡す・手順書付き） | 15名以上・専任担当がいる層のみ |
| 同上（継続形） | **共同開発会**（月5万・月1回90分・いつでも終了可・実装は別建て22万/様式）。LP上は「**選べます。義務ではありません**」と権利として書く | 同上 |
| AIを使える組織にする | **社内AI利用ルールと変更管理の整備**（48万・6週間＋年次見直し18万）。顧客情報を外部AIに入れない基準・ツール管理台帳・改修承認フロー | D級以上。**Eが紹介できる唯一の商材** |

言い回しの変換原則（事業モデル担当）: **「御社内で自走できるレベルまで支援します」は義務（学習）を渡す言い方。「ルール表の編集権を御社にお渡しします」は権利を渡す言い方。同じ内容で受信が逆になる。**

**看板（ヒーロー）は納品型のまま動かさない。** 自走要素は進め方のステップ4に「選択肢」として置く（§4 P8）。

## 3. 実装LPの診断 —「訴求が沸かない」の正体

### 買い手が指摘した4つの欠落

1. **人の顔がない**（3名全員）。「『20年の実務者が一人で担当します』と書いてあるのに、その人がどこにもいない。スクロールする前に閉じます」（A）。1人でやることの唯一の強みを隠している
2. **Beforeの汚い絵がない**（A）。「右のモックはうまくいっている絵だけ。**Excelが3つ開いていてコピペの矢印が交差している汚い絵**を見せられたら『うちだ』と思う。**きれいなモックは他人事に見えます**」
3. **損失額がない**（A）。「30万円だけが大きく出ていて、隣に比べる数字がない。月100件の更改で事務2名が月32時間＝**年70万円**。これが書いてあれば30万は『安い』になる。書いていないから**ただの30万**に見える」
4. **会社概要ページがない**（D）。「ナビに『会社概要』がない。これが無い限り、内容を評価する前に委託先審査に上げられない」

### デザイナーの診断: 真因は「リズムの欠落」

> このLPは72px W800の黒が最も重く、それ以外がほぼ同じ軽さで並んでいる。**72pxと17pxの間に中間段がない**。「30万円」が2つ目にして最後の山で、7セクションで山が2つは少なすぎる。**感情はリズムから生まれる**ので、段差が1つしかないページは何度スクロールしても盛り上がらない。

### コピー担当の診断: 売り手の野心を消していた

> 買い手の恐怖を消すコピーは、売り手の野心を消すコピーでもある。否定形が多い（預かりません/電話しません/約束しません）ため、買い手には安全だが、運営者が名刺代わりに見せたとき「自分は転記ツールの職人」に見える。処方は「**買い手の言葉で入り、運営者の言葉で締める**」。

### その他の実装上の問題（原因特定済み）

- **ロゴの白箱**: `cocreo-logo.png` は `8-bit/color RGB`——**アルファチャンネルが存在しない**。白は透過ではなく白ピクセルで、CSSでは直らない。SVG化が必要
- **黒CTAボタン**: `#1C1917` は見出しと同色で主役が競合。ブランド色 `#C2410C` の枠線ボタンに（ベタは⑦問い合わせのみ＝序列を作る）
- **「説明用ダミー」注記の2連続**: 2回目で「実物がないんだな」と読まれる。3枚目に実物スクショ（SubsidyGenerator・稼働中の自社資産）を置き、注記を書き分ける（モック=「画面イメージです」控えめ／実物=「**これは実際の画面です**」強調）
- `og:image` が相対パスで**共有プレビューが出ていない**。絶対URL化＋1200×630専用画像が必要
