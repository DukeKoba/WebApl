## 5. ブランド・ビジュアル（確定）

### 5-1. ブランドカラーは `#C2410C`（レンガ寄りオレンジ）に確定

- `#F26522` は**損保ジャパン等のオレンジと同色相帯（H=15〜20°）**。乗合代理店向けの中立性と構造的に衝突する。A「事務所で『ここは損保ジャパンさんの店ですか』と聞かれたことが本当にある」／D「販促物の色が特定社を連想させると他社担当者から実際に指摘を受ける」／E「特定社のコーポレートカラーに近い色は避けてほしい」——**3名とも変更妥当と判定**
- `#C9891F`（現LP実装の金茶）は白背景コントラスト3.02:1でWCAG AA不合格。50代主読者に対して使えない

```css
:root {
  --brand:        #C2410C; /* 白上 5.18:1 AA合格。ボタン地・リンク文字を1色で賄える */
  --brand-hover:  #9A3412;
  --brand-tint:   #FFF4ED;
  --brand-line:   #F0D3C2;
  --ink:          #1C1917; /* 白上 17.5:1 AAA */
  --ink-sub:      #57534E;
  --ink-muted:    #78716C;
}
```

**X資産（アイコン・ヘッダー）も同日に `#C2410C` へ更新する**（0.25人日）。混在期間を1日も作らない——混在期間の存在こそが「相手によって顔を変える」に見えるため。対象4面: Xアイコン／Xヘッダー／`insurance-news/support.html` の `--orange` 系3変数／`CARD_PALETTES.ember.rule`。これで3系統分裂（#F26522/#C9891F/紫）が1色に収束する。
