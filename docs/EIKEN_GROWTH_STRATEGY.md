# AI英検Pass 成長戦略（ダウンロード数・サブスク数向上）

作成日: 2026-07-05
対象: OptimaLrn「AI英検Pass」シリーズ（準2級 / 準2級プラス / 2級 / 準1級）+ X運用（@optimalrnai）

---

## 1. 現状の課題（なぜ伸びていないか）

### X運用の構造的な問題
これまでの投稿（sns_posts の履歴）には、伸びない原因がはっきり出ている。

1. **全投稿が広告になっている**
   すべての投稿に App Store リンク + CTA が付く設計だった。Xのアルゴリズムは外部リンク付き投稿のリーチを大きく下げるため、「毎回リンク付き」はフォロワー外にほぼ届かない。しかもフォロワーから見ると全部宣伝なので、フォローする理由がない。

2. **信頼を毀損する演出が混ざっていた**
   「合格者の98%が知ってる」「受験生の92%が間違える」「残り2時間限定」「正解者にプレゼント」— 出典のない統計、実施していない企画、いいね・RT乞い。学習アカウントの生命線は正確さと信頼。この種の投稿は1回でアカウントの評価を下げる。

3. **クイズの正解を同じ投稿内に書いていた**
   読者は3秒で読み終わって流す。リプ・引用・ブックマークが発生せず、アルゴリズム上の評価が上がらない。

4. **試験日カウントダウンが壊れていた**
   `EXAM_DATES` が 2級のみ・2026-05-31（過去日）にハードコードされ、「1次試験まであと0日！」という投稿が生成され続ける状態だった。

5. **ハッシュタグ過多**（3〜7個）。Xでは2個までが最適とされ、多いほどスパム判定に近づく。

### プロダクト側の課題（外から見える範囲）
- 無料→有料の導線・課金の訴求がLP・ストアに見えない（何が無料で何が有料か不明）
- アプリからSNSへ還流する仕組み（シェア機能）がない
- 4アプリが独立しており、級が上がるたびに顧客を失う構造（準2級合格→準2級プラスへの導線が弱い）

## 2. X運用の新戦略（今回コードに実装済み）

### 基本方針: 「価値8 : 宣伝2」+「答えはリプ欄」
リーチはリンクなしの価値投稿で稼ぎ、変換はリプ欄とプロフィールで行う。

実装した3つの投稿フォーマット（`/api/eiken/generate` の `format` パラメータ）:

| フォーマット | 内容 | リンク | 用途 |
|---|---|---|---|
| `quiz_reply`（推奨・語彙/文法のデフォルト） | 本文=4択クイズ（正解は書かない）、解答・解説+アプリリンクは**リプライで自動スレッド投稿** | リプ側のみ | 毎日の主力。リプ欄参加でエンゲージメント最大化 |
| `value` | リンクなしのTips投稿 | なし | 学習法・入試情報・文化表現など |
| `promo` | 本文にApp Storeリンク | 本文 | **週1回まで**。機能紹介・アップデート告知 |

### 実装済みのその他の変更
- **試験日程の自動更新**: 2026年度の全日程（第2回 2026-10-04、第3回 2027-01-24）を登録し、過去日を自動スキップ。カウントダウンは**試験60日前から**のみ付与（「あと180日」は訴求力がなく文字数の無駄）
- **コンテンツ品質ルールを全生成プロンプトに注入**: 架空の統計・偽の限定企画・いいねRT乞い・誇大断定を禁止。冒頭1行は具体的なフック必須
- **ハッシュタグを2個までに削減**
- **公開時のスレッド投稿対応**（xService に reply 対応を追加）
- **編集内容が投稿に反映されないバグを修正**（プレビューで編集→投稿すると編集前のテキストが投稿されていた）

### 週間投稿カレンダー（推奨・1日1〜2投稿）

| 曜日 | 朝（7:00-7:30 通学時間） | 夜（21:00-22:00 勉強終わり） |
|---|---|---|
| 月 | 語彙クイズ（quiz_reply） | — |
| 火 | 文法クイズ（quiz_reply） | 学習のコツ（value） |
| 水 | 語彙クイズ（quiz_reply） | — |
| 木 | **大学入試×英検情報（value）** | 英語耳・リスニング（value） |
| 金 | 語彙クイズ（quiz_reply） | — |
| 土 | AI活用Tips（value） | **アプリ紹介（promo・週1のここだけ）** |
| 日 | 文化表現・雑学（value） | 面接Tips（二次試験前の期間） |

- **大学入試×英検情報（木曜）は最重要枠**。「英検2級でMARCHに出願できる」系の投稿は検索流入・保存・拡散すべてが強く、既存の大学受験タブのコンテンツがそのまま使える。大学名が検索に引っかかるのも大きい
- 試験申込開始日・締切日・試験1週間前・合否発表日は臨時投稿（この4日はアクセスが跳ねる日）
- **プロフィールと固定ポストが変換装置**: bio に「AIが弱点だけ出題する英検アプリ」+ LPリンク、固定ポストに promo 投稿（アプリのスクショ/デモ動画付き）を常設。value 投稿で来た人はプロフィール経由でDLする

### 運用のコツ
- クイズ投稿から30分〜2時間は正解リプを遅らせる手動運用も有効（リプ欄で回答が集まってから解答リプを出す）。現状は同時スレッド投稿なので、伸びてきたら「解答リプの遅延投稿」を次の改善として実装する
- 画像付き投稿（単語カード画像・4択の画像化）はテキストのみより明確にリーチが上がる。Canva等でテンプレを1つ作り、クイズ本文を流し込むだけの運用を推奨

## 3. マーケティング施策（コード外・優先度順）

### P0: ASO（App Store最適化）— 費用ゼロで最も効く
- **キーワード**: 「英検 過去問」「英検 単語」「英検2級 リスニング」等をタイトル/サブタイトルに。現状の「AI英検準２級 Pass」だけでは「AI」で探す人にしか届かない。サブタイトル例:「過去問形式の問題をAIが弱点だけ出題」
- **スクリーンショット1枚目**が実質の広告。「AIが弱点を特定→そこだけ出題」のビフォーアフターを1枚目に
- **レビュー獲得**: 「模試で合格ライン到達」「7日連続学習」など成功体験の直後に `SKStoreReviewController` でレビュー依頼（アプリ側実装）。件数が2桁になるまでは検索順位が上がりにくい

### P0: 検定日連動マーケティングカレンダー
英検アプリの需要は年3回の試験に完全連動する。次のスパイクは**第2回申込開始（8月）〜試験日（10/4）**。
- 8月上旬: 「申込開始」告知 + 「今から2ヶ月で間に合う学習プラン」スレッド
- 9月: 直前対策コンテンツを増量、カウントダウン自動付与が始まる（60日前〜）
- 試験翌日: 「解答速報を見て次にやること」/ 合否発表日: 「不合格だった人へ、次回までのプラン」→ このタイミングが最大のDL獲得機会

### P1: TikTok / Reels / YouTube Shorts
台本生成は実装済み。X より10代へのリーチ効率が高く、英単語クイズ系ショートは定番で伸びるジャンル。週2本から。Xのクイズと同素材の使い回しでよい。

### P1: LP（OptimaLrnランディング）の改善
- 料金（無料でどこまで/サブスクで何が解放されるか）を明記 — 現状不明でDLの心理障壁
- アプリの実スクリーンショット掲載（現状は抽象アイコンのみ）
- 「英検®は公益財団法人日本英語検定協会の登録商標です。このコンテンツは同協会の承認や推奨を受けていません」の注記を追加（商標ガイドライン対応。ストア審査・信頼性の両面で必要）

### P2: 保護者・塾チャネル
準2級以下の課金決定者は保護者。保護者向け投稿（「子どもの英検、親は何をすればいい？」）を月数回。塾向けには無料の進捗共有機能（下記プロダクト施策）が営業ツールになる。

## 4. プロダクト施策（サブスク転換率向上・アプリ側）

### P0: オンボーディングで「30秒で価値体験」
初回起動→「試験日はいつ？」→ミニ診断5問→**弱点レポート+合格までの逆算プラン**を即提示。「AIが弱点を特定する」という売りを、課金前に一度体験させる。試験日入力はプッシュ通知・カウントダウンの基盤にもなる。

### P0: ペイウォール設計の定石
- 無料: 1日10問 + 弱点レポート閲覧
- サブスク: 無制限演習 / 模試 / 弱点集中モード / 英作文AI添削
- **試験日が近いほど転換率が上がる**ので、「試験まであと○日。今のペースでは間に合いません」という文脈でペイウォールを出す
- 年額プラン or「検定1回分パス（3ヶ月）」の買い切りは学生の心理に合いやすい

### P1: 継続の仕組み（サブスク維持率＝LTV）
- 学習ストリーク + 試験日カウントダウン通知（「あと45日。今日の10問」）
- 週次レポート通知（正答率の推移）— 保護者共有機能にすると準2級以下で刺さる

### P1: バイラルループ（アプリ→SNS還流）
- 模試結果・ストリークの**シェアカード画像**（「英検2級模試 82% #AI英検Pass」）を1タップでX/Instagramへ。ユーザー投稿が最良の広告であり、Xアカウントの UGC 素材にもなる
- 合格報告キャンペーン（合格スクショ投稿をリポスト）は信頼できる社会的証明

### P2: 級間の導線（4アプリ構造の弱点補強）
- 合格・高スコア到達時に「次の級のアプリへ」誘導（準2級→準2級プラス→2級→準1級）
- 中期的には全級バンドルのサブスク「OptimaLrn Pass」を検討（1つの課金で全アプリ解放）。級が上がるたびに解約される構造を解消できる

## 5. KPIと計測

| ファネル | 指標 | 最初の目標 |
|---|---|---|
| X | インプレッション/投稿、プロフィールアクセス率 | value投稿でフォロワー数×3のimp |
| 流入 | LP訪問→App Store遷移率 | 計測導線の設置（App Store Connectのキャンペーンリンク） |
| DL | 週次DL数、検索キーワード順位 | レビュー20件、主要KW 50位以内 |
| 転換 | DL→トライアル率、トライアル→課金率 | オンボーディング完了率 60% |
| 継続 | D7/D30リテンション、サブスク更新率 | 通知許諾率 50% |

X→ストアの帰属は正確には取れないため、**promo投稿・プロフィールのリンクにApp Store Connectの「キャンペーンリンク」を使い分けて**流入元を推定する。
