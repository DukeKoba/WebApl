# ShiftSync - シフト管理プラットフォーム

汎用的なシフトスケジューリングWebアプリケーション。アルバイト、パートタイム、正社員など、あらゆるチーム・組織のシフト管理に対応。

## 主な機能

### シフト自動生成
- メンバーの勤務可能時間とスキルに基づく自動スケジューリング
- 公平な時間配分アルゴリズム（最小時間のメンバーを優先割当）
- 週の最大勤務時間制限の自動遵守
- 人員不足の自動検出と警告

### 欠勤・代替管理
- 欠勤登録時の自動代替スタッフ検出
- 適合度スコアによる最適な代替候補の提案
- ワンクリックでの代替割当
- シフト交換リクエスト機能

### メンバー管理
- 勤務可能時間の曜日別設定
- スキル管理（調理、レジ等）
- 時給・最大勤務時間の設定
- 役割管理（スタッフ/リーダー/マネージャー）

### ダッシュボード
- メンバー稼働時間の可視化
- 未処理の欠勤・交代リクエスト表示
- アクティブスケジュール一覧

### 汎用性
- 飲食店、小売、倉庫、オフィス、医療、教育、イベント等に対応
- 複数組織の管理
- スキルベースのシフト割当

## セットアップ

```bash
# 依存関係インストール
npm install
cd server && npm install
cd ../client && npm install

# 開発サーバー起動
cd .. && npm run dev
```

- フロントエンド: http://localhost:5173
- API: http://localhost:3001

## 技術スタック

- **Frontend**: React 18, Vite, TailwindCSS, React Router, Lucide Icons
- **Backend**: Express.js, better-sqlite3
- **Database**: SQLite（セットアップ不要）
